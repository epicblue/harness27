# 项目文档

Harness27 用本机已部署的 27B 模型完成受限 Agent 任务，并通过小型、可复跑的 benchmark 摸清实际能力边界。文档入口：

- [使用说明](USER_GUIDE.md)：环境准备、运行 harness、参数、工具和安全注意事项。
- [使用场景实例](USE_CASES.md)：配置提取、敏感约束、CSV 对账、代码修复和日志巡检的端到端示例。
- [能力评测手册](BENCHMARK_GUIDE.md)：评测用例、命令行、报告解读、扩展用例和实验规范。
- [系统设计文档](DESIGN.md)：模块架构、类图、交互式 Harness 与 benchmark 完整时序图、接口、安全模型和限制。

仓库根目录的 [README](../README.md) 是项目简介和快速入口。权重、推理服务和实际部署配置不包含在本仓库中。当前四用例 suite 属早期 smoke suite；在真实 27B 服务上运行并保存配置前，不应将本仓库测试结果解释为模型实测结论。
